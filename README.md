# Mercazon 🛒

Tienda online de demostración con estética tipo Amazon, hecha en un solo archivo HTML (HTML + CSS + JavaScript, sin dependencias).

## Funciones
- Buscador en vivo y filtro por categoría
- Filtros por valoración, rango de precio, prime y ofertas
- Ordenar por precio, valoración o reseñas
- Ficha de producto en ventana modal
- Carrito lateral con cantidades, subtotal y barra de envío gratis (se guarda en el navegador)
- Diseño responsive (celular, tablet y escritorio)

## Cómo usarla
Abre `index.html` en tu navegador. ¡Listo!
